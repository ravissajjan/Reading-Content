____ / 5Quiz 1 — Introduction to Microservices

After Session 1

1. What most accurately defines a monolith?

  1. a)One codebase deployed as a single unit
  2. b)Badly written or poorly structured code
  3. c)An application that does not use a database
  4. d)Any application older than five years

2. A team of four is building their first product and has no users yet. What is usually the right choice?

  1. a)Microservices, so they never have to go through a migration later on
  2. b)Microservices, because that is what modern engineering teams do
  3. c)A monolith, because it is simpler and they do not yet know the boundaries
  4. d)One service per developer, so everyone owns their own deployable

3. Two features always change together and always ship together. They should most likely be:

  1. a)In two services, so they can stay independent
  2. b)In the same service, deployed as one unit
  3. c)In two services sharing a single database
  4. d)In the API gateway, which calls both

4. Which is a genuine advantage of microservices?

  1. a)There is less total code to write than in a monolith
  2. b)There are fewer moving parts that can fail at runtime
  3. c)Debugging a request across the system becomes easier
  4. d)You can scale and deploy one part without touching the rest

5. “Database per service” means:

  1. a)Every service is required to use a different database product from all of the others
  2. b)Each service owns its own data and other services cannot reach into it directly
  3. c)Each service needs its own physical server to store that data on
  4. d)Every database must be duplicated so that a backup always exists

After Session 4  ·  Name: ______________________________

1. You deleted a pod and a new one appeared by itself. Which object made that happen?

  1. a)The Pod
  2. b)The Service
  3. c)The Deployment
  4. d)The container image

2. “Desired state” means:

  1. a)The state that the system was in the last time it was known to be working correctly
  2. b)You declare what you want, and the platform continuously repairs reality to match
  3. c)A backup of the cluster taken immediately before a deployment

3. You scaled catalog to 5 and left orders at 1. What is the point?

4. What does a rolling update do?

  1. a)Replaces instances gradually so the service stays available throughout
  2. b)Stops every instance, then starts them all again on the new version
  3. c)Rolls the database back to the state it was in the previous day
  4. d)Applies updates only during a scheduled weekend maintenance window

5. Which is the strongest reason NOT to adopt microservices?

  1. a)Writing the application code itself takes noticeably longer than it would in an equivalent monolith
  2. b)They use more disk space and memory than an equivalent monolith would use
  3. c)Your team is small, the boundaries are unclear, and the operational cost exceeds the benefit
  4. d)They cannot be run at all without Kubernetes or a managed cloud provider
